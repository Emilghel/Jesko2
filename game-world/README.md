# Lumen Isles

A small explorable low-poly 3D world built with three.js (single HTML file, no build step).

- Procedural island from seeded simplex noise: beaches, meadows, forests, rocky ridges, snowy peaks
- Animated water, drifting clouds, a full day/night cycle with stars, sun and moon
- Third-person explorer with walking, running, jumping and swimming
- 12 glowing shards to find, with a distance and compass hint
- Keyboard + mouse on desktop; virtual joystick, drag-to-look and pinch zoom on touch

Open `index.html` in a browser (it loads three.js r128 from cdnjs). `world.html` is the same page without the outer document tags, used for publishing as a Claude artifact.

Controls: WASD / arrows to walk, Shift to run, Space to jump, drag to look, scroll to zoom. "New island" generates a fresh seed.
